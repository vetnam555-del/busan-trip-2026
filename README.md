## 도쿄 4박 5일 · 2026.10.01–05 (`tokyo/`)

3인 가족(부모님 동반) 기준 일정입니다. 숙소(신주쿠교엔마에역 1분) 앞 마루노우치선을 축으로, 하루에 한 방향만 다녀오도록 짰습니다.

| 날 | 동선 |
| --- | --- |
| 10/1 목 | YP735 인천 13:50 → 나리타 T2 16:30 · N'EX 교환 → 신주쿠 · 라멘 |
| 10/2 금 | 가마쿠라 당일치기(쓰루가오카하치만구 → 시라스동 → 대불·하세데라 → 가마쿠라코코마에 건널목) → 저녁 오모이데요코초 |
| 10/3 토 | 메이지신궁 → 마이센 돈카츠 → 에비스 그릇 가게(THE HARVEST · EAST table) → 시부야 스카이 일몰 → 스시노미도리 |
| 10/4 일 | 센소지 → 이마한 스키야키 → 긴자 보행자천국 → 우나후지 오페라시티점 53층 저녁 |
| 10/5 월 | 체크아웃 → 신주쿠역 쇼핑 → N'EX 12시대 → 나리타 **T3** · ZE610 16:20 |

### 기능

- **한국어 / 日本語 전환** — 맨 위(데스크톱은 왼쪽 아래) 버튼으로 설명문이 통째로 일본어로 바뀝니다. 가게·장소 이름은 일본어 이름 아래에 한국어 이름을 함께 표시합니다. 선택한 언어는 기기에 저장됩니다.
- **출발 전 카드** — 여행 전에는 맨 위에 '출발 N일 전'과 아직 체크하지 않은 필수 할 일이 뜹니다. 할 일마다 예약·신청 공식 페이지 링크가 붙어 있습니다.
- **캘린더 알림** — 비행기·N'EX·가마쿠라 출발·시부야 스카이·이마한·우나후지 등 시간이 정해진 11개 일정을 `.ics` 파일로 휴대폰 캘린더에 넣습니다(미리 알림 포함).
- **보여주기 카드** — 숙소 주소(택시), N'EX 좌석 지정 요청, 식당·쇼핑에서 쓰는 한마디를 화면 가득 일본어로 띄웁니다. 발음과 한국어 뜻을 함께 표시합니다.
- **여행 중 모드** — 여행 날짜에는 맨 위에 '오늘' 카드와 지금/다음 일정이 뜨고, 지난 일정은 흐려지고 지금 일정에 '지금' 표시가 붙습니다.
- **길찾기** — 식당·명소·숙소마다 구글 지도 대중교통 길찾기로 바로 연결됩니다.
- **내 위치** — 켜면 숙소·다음 장소·각 일정까지의 거리와 도보 시간이 뜹니다. 위치는 휴대폰 안에서만 계산합니다.
- **실시간 날씨** — Open-Meteo 예보로 여행 5일의 날씨와 강수확률을 보여줍니다(가마쿠라 날은 가마쿠라 예보). 50%를 넘는 날은 그 날 머리글에 '비 오면 이렇게' 링크가 뜨고, 여행 중에는 '오늘' 카드에 그 날 날씨가 붙습니다. 마지막 예보를 저장해 두어 데이터가 없어도 보입니다.
- **운행 정보** — 도쿄메트로·도에이·JR·에노덴 공식 운행 정보 페이지로 바로 연결됩니다.
- **링크 보내기** — 가족에게 페이지 링크를 공유하고, 홈 화면에 추가하는 방법을 안내합니다.
- **실제 축척 지도** — 숙소와 날짜별 목적지, 마루노우치선·야마노테선을 역 좌표로 그렸습니다. 2일차에는 에노덴과 걷는 구간을 그린 가마쿠라 약도가 따로 있고, 날마다 구글 지도로 하루 동선을 여는 버튼이 있습니다.
- **체크리스트** — 출국 전 할 일, 준비물. 체크 상태가 기기에 저장됩니다.
- **엔 → 원 계산기** — 인터넷이 되면 오늘 환율(Frankfurter/ExchangeRate-API)로 자동으로 바뀌고, 직접 넣을 수도 있습니다. 예상 경비 표도 같이 환산됩니다.
- **글자 크게 · 밝게/어둡게** — 부모님 휴대폰용 큰 글씨 모드. 설정은 기기에 저장됩니다.
- **오프라인** — 한 번 열어두면 지하철 안처럼 데이터가 없어도 열립니다. 저장이 끝나면 맨 아래에 표시됩니다.
- **반응형** — 모바일은 상단 노선도 모양 내비게이션, 데스크톱(1024px 이상)은 좌측 세로 노선도.

## 부산 2박 3일 · 2026.08.22–24 (루트)

김해공항 도착부터 귀국까지의 여행 일정 페이지입니다.

### 기능

- **한국어 / 日本語 전환** — 설명문이 통째로 바뀝니다. 가게·장소 이름은 언어와 상관없이 한글과 일본어를 함께 표시해, 그대로 택시 기사나 점원에게 보여줄 수 있습니다.
- **주소 복사 버튼** — 각 장소의 도로명 주소를 클립보드로 복사합니다. 카카오T에 붙여넣거나 화면째 보여주면 됩니다.
- **네이버지도 바로가기** — 구글맵은 한국에서 길찾기가 제한되므로 네이버지도로 연결했습니다.
- **준비물 체크리스트** — 체크 상태가 기기에 저장됩니다.
- **밝게 / 어둡게 전환** — 기본값은 기기 설정을 따릅니다.
- **반응형** — 모바일은 상단 탭 내비게이션, 데스크톱(1024px 이상)은 좌측 고정 사이드바로 전환됩니다.

### 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 전체 (CSS·JS 인라인, 외부 의존성 없음) |
| `icon.svg` | 파비콘 및 홈 화면 아이콘 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때의 앱 이름·색상 |
| `sw.js` | 오프라인 캐시 (`busan-trip-*`, `tokyo/` 요청은 건드리지 않음) |
