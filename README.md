### 기능

- **한국어 / 日本語 전환** — 맨 위(데스크톱은 왼쪽 아래) 버튼으로 설명문이 통째로 일본어로 바뀝니다. 가게·장소 이름은 일본어 이름 아래에 한국어 이름을 함께 표시합니다. 선택한 언어는 기기에 저장됩니다.
- **출발 전 카드** — 여행 전에는 맨 위에 '출발 N일 전'과 아직 체크하지 않은 필수 할 일이 뜹니다. 할 일마다 예약·신청 공식 페이지 링크가 붙어 있습니다.
- **날씨 알림** — 10/1 밤 기준 예보로 10/2 비·쌀쌀(가마쿠라는 10/3 추천), 10/1 밤 공항 → 신주쿠 N'EX 시각, 태풍 27호(10/4~5 확인)를 알려 주고 태풍 진로·N'EX·JR 운행정보·ZE610 운항으로 바로 연결합니다. 10/1 밤 항목은 10/2 새벽에, 가마쿠라 항목은 10/2 정오에, 알림 전체는 10/5 17시에 자동으로 사라집니다.
- **이 폰에만 저장하는 정보** — 숙소 주소·가족 연락처·못 먹는 음식을 기기(localStorage)에만 저장해 택시·길 잃음·가족 전화·식사 카드에 크게 띄웁니다. '가족 폰에도 저장하기'는 정보를 링크의 `#` 뒷부분에 담아 보내므로 서버에는 전달되지 않습니다(받은 대화방에는 남습니다).
- **항공편 실시간 상태** — 예약 카드에서 FlightAware, 항공사, 나리타 출발 안내로 연결합니다.
- **QR 코드 · 카카오톡 안내** — 옆 가족 폰 카메라로 바로 여는 QR(선택한 가마쿠라 날짜 포함). 카카오톡 안에서 열리면 기본 브라우저로 여는 버튼을 보여줍니다.
- **오늘 카드의 비·바람 시각** — 여행 중에는 시간대별 예보로 '13시쯤부터 비', '바람 강함'을 알려 줍니다.
- **가마쿠라 날짜 선택** — 10/2와 10/3의 낮 일정을 교환하고(저녁은 날짜 고정) 선택을 기기와 공유 URL에 저장합니다. 오전 9시~오후 4시의 비·바람을 비교하며, 예보 누락이나 오래된 캐시를 구분합니다.
