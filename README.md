## 도쿄 4박 5일 · 2026.10.01–05 (`tokyo/`)

3인 가족(부모님 동반), 신주쿠교엔마에 주변 숙박 기준입니다. 2026-09-27에 웹·엑셀·캘린더를 맞췄습니다. 아래 시각은 예약 확정이 아닌 계획이며 실제 항공권·예약 내역이 우선입니다.

시부야 스카이는 제외했습니다. 가마쿠라는 날씨·피로에 따라 10/3으로 바꿀 수 있으며, 2·3일의 하루 일정과 캘린더가 함께 바뀝니다. 식당 예약이나 이미 가져온 개인 캘린더는 자동으로 바뀌지 않습니다.

### 기능

- **한국어 / 日本語 전환** — 맨 위(데스크톱은 왼쪽 아래) 버튼으로 설명문이 통째로 일본어로 바뀝니다. 가게·장소 이름은 일본어 이름 아래에 한국어 이름을 함께 표시합니다. 선택한 언어는 기기에 저장됩니다.
- **출발 전 카드** — 여행 전에는 맨 위에 '출발 N일 전'과 아직 체크하지 않은 필수 할 일이 뜹니다. 할 일마다 예약·신청 공식 페이지 링크가 붙어 있습니다.
- **가마쿠라 날짜 선택** — 10/2와 10/3의 일정을 교환하고 선택을 기기와 공유 URL에 저장합니다. 오전 9시~오후 4시의 비·바람을 비교하며, 예보 누락이나 오래된 캐시를 구분합니다.
- **캘린더와 엑셀** — 선택한 날짜안의 계획 33개를 `.ics`로, 기본 일정과 식당·카페 21곳을 `.xlsx`로 내려받습니다. 이전 캘린더를 제거하고 한 가지 안만 가져오세요. 캘린더 시각은 미확정 계획입니다.
- **카페 6곳** — 기본 카나데와 네즈·나카지마·사샤·오리엔토·사후를 교체 후보로 구분합니다. 전부 방문하는 일정이 아닙니다.
- **보여주기 카드** — N'EX 좌석 지정 요청과 식당·쇼핑 표현을 일본어·발음·한국어로 표시합니다. 정확한 숙소 주소는 예약 앱이나 개인 보관 파일에서 확인합니다.
- **여행 중 모드** — 여행 날짜에는 맨 위에 '오늘' 카드와 지금/다음 일정이 뜨고, 지난 일정은 흐려지고 지금 일정에 '지금' 표시가 붙습니다.
- **지도** — 식당·명소의 지점을 구글 지도에서 확인합니다. 실제 이동편은 당일 길찾기로 확인하세요.
- **내 위치** — 동의 후 신주쿠교엔마에역·좌표가 등록된 일정까지의 거리를 표시합니다. 위치는 기기 안에서 계산합니다.
- **실시간 날씨** — Open-Meteo 예보로 여행 5일의 날씨와 강수확률을 보여줍니다(가마쿠라 날은 가마쿠라 예보). 50%를 넘는 날은 그 날 머리글에 '비 오면 이렇게' 링크가 뜨고, 여행 중에는 '오늘' 카드에 그 날 날씨가 붙습니다. 마지막 예보를 저장해 두어 데이터가 없어도 보입니다.
- **운행 정보** — 도쿄메트로·도에이·JR·에노덴 공식 운행 정보 페이지로 바로 연결됩니다.
- **링크 보내기** — 가족에게 페이지 링크를 공유하고, 홈 화면에 추가하는 방법을 안내합니다.
- **지역 지도** — 주요 지역의 위치 관계를 보여줍니다. 실제 방문 순서는 날짜별 일정에서 확인합니다.
- **체크리스트** — 출국 전 할 일, 준비물. 체크 상태가 기기에 저장됩니다.
- **엔 → 원 계산기** — 온라인 환율 조회와 직접 입력을 지원합니다. 가족 식비·입장료 예산은 엔화 기준이며 항공·숙박·교통·쇼핑은 별도입니다.
- **글자 크게 · 밝게/어둡게** — 부모님 휴대폰용 큰 글씨 모드. 설정은 기기에 저장됩니다.
- **오프라인** — 한 번 열어두면 지하철 안처럼 데이터가 없어도 열립니다. 저장이 끝나면 맨 아래에 표시됩니다.
- **반응형** — 모바일은 상단 노선도 모양 내비게이션, 데스크톱(1024px 이상)은 좌측 세로 노선도.

### 출발 전에 직접 확인할 것

영업시간·요금은 2026년 9월에 조사한 값입니다. 아래는 페이지에 확정값을 넣지 못했습니다.

- **N'EX 실제 지정석** — 10/5 T3 13:00~13:20 도착을 만족하는 열차. 일정의 11:00은 계획용 표시이며 확정 열차 시각이 아닙니다.
- **항공권·숙소** — 실제 항공사 앱의 터미널·운항·수하물, 숙소 예약 앱의 주소·체크아웃 마감.
- **우나후지 10/4 17:00, 카나데 14:00, 저녁 식당** — 빈자리·좌석·취소 조건은 별도 확인. 예약을 대행하지 않았습니다.
- **가마쿠라 날짜** — 9/30과 10/1 저녁에 낮 시간대 비·바람·운행을 확인. 2·3일 교환 전에 식당 예약 변경 가능 여부를 확인합니다.
- **가족 이동 조건** — 계단·승강기·알레르기·생식 메뉴. 보통열차 그린차는 자유석이므로 착석을 보장하지 않습니다.

정확한 숙소 주소·호스트 연락처·결제 정보는 공개 페이지에서 제외하고 로컬 개인 보관 파일로 분리했습니다. `noindex`는 비공개 기능이 아니며 Git 이력을 삭제한 것은 아닙니다.

## 부산 2박 3일 · 2026.08.22–24 (루트)

### 기능

- **한국어 / 日本語 전환** — 설명문이 통째로 바뀝니다. 가게·장소 이름은 언어와 상관없이 한글과 일본어를 함께 표시해, 그대로 택시 기사나 점원에게 보여줄 수 있습니다.

- **밝게 / 어둡게 전환** — 기본값은 기기 설정을 따릅니다.
- **반응형** — 모바일은 상단 탭 내비게이션, 데스크톱(1024px 이상)은 좌측 고정 사이드바로 전환됩니다.
